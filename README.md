### Alper Alyaz

I run [Hidroteknik](https://www.hidroteknik.com.tr), a hydraulics and pneumatics company in Denizli, Türkiye, founded in 1984.
I'm an engineer and an operator. Software is not my trade.

Most of the code here was written with AI coding agents, which is why the repos carry `CLAUDE.md` files.
I choose the problems, make the design calls and answer for the bugs. I publish the parts that might be useful to someone else.

**Things I've built**

- [**handwrite**](https://github.com/alperalyaz/handwrite) turns a photo of your handwriting into an OpenType font, with no template grid to fill in. A language model reads what the page says and dynamic programming finds where each letter sits. One notebook page becomes an 87-glyph font in about 30 seconds. Python, MIT. The web UI is Turkish only for now.
- [**debate.be**](https://github.com/alperalyaz/siyaset_meydani) is an AI talk show where historical figures argue with each other and you host. Guests interrupt mid-sentence, concede a point now and then, and answer when you call them by name. It runs at [debate.be](https://debate.be) with no sign-up, in English and Turkish. MIT.
- [**Hydraulic & Pneumatic Calculator**](https://github.com/alperalyaz/hpcalculator) has 12 calculators for cylinder force, pump selection, accumulator sizing, rod buckling, thread identification and more. These are the calculations our engineers and service technicians do every day. Free on the [web](https://calculate.hidroteknik.com.tr) and on [Android](https://play.google.com/store/apps/details?id=com.hidroteknik.hydrauliccalculator), in English and Turkish. MIT.
- [**HushDown**](https://github.com/alperalyaz/hushdown) is a Chrome extension that files downloads under the project you are working on, gives them numbered, readable names and keeps a list of where each file came from. Nothing leaves your browser.

**Smaller things**

- [**KanbanCode**](https://github.com/alperalyaz/KanbanCode) is my fork of [Agent Teams AI](https://github.com/777genius/agent-teams-ai) by 777genius, a desktop kanban board for running teams of coding agents. The original design is theirs. AGPL-3.0.
- [**arduino-araba**](https://github.com/alperalyaz/arduino-araba) brings a years-old obstacle-avoiding robot car back to life. The original code is lost, so it is being rewritten from scratch. Unfinished, notes in Turkish.
